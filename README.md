# اپلیکیشن مدیریت سفارشات (Kivy / Android)

اپلیکیشن مدیریت شرکت‌ها و کالاهای سفارشی، نوشته‌شده با پایتون و Kivy، آماده برای ساخت APK از طریق GitHub Actions (بدون نیاز به نصب Android Studio روی سیستم شما).

## ساختار پروژه
```
main.py                      کد اصلی اپلیکیشن
buildozer.spec                تنظیمات بیلد اندروید
assets/fonts/Vazirmatn-Regular.ttf   فونت فارسی
.github/workflows/build.yml   بیلد خودکار APK با گیت‌هاب اکشن
```

## مراحل ساخت APK با گیت‌هاب (بدون نیاز به سیستم قوی)

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `order-app`).
2. تمام فایل‌های این پروژه (همین ساختار پوشه‌ها) را در آن آپلود/پوش کنید:
   ```bash
   git init
   git add .
   git commit -m "اولین نسخه اپلیکیشن"
   git branch -M main
   git remote add origin https://github.com/USERNAME/order-app.git
   git push -u origin main
   ```
3. به تب **Actions** در صفحه ریپازیتوری بروید. یک اجرای خودکار به نام «Build Android APK» شروع می‌شود (چون فایل workflow در پوشه `.github/workflows` قرار دارد).
4. حدود ۱۵ تا ۲۵ دقیقه صبر کنید تا بیلد تمام شود (اولین بار به‌خاطر دانلود Android SDK/NDK کمی طول می‌کشد).
5. وقتی بیلد سبز شد، وارد همان اجرا (run) شوید و در پایین صفحه بخش **Artifacts** را باز کنید؛ فایل `order-app-apk` را دانلود کنید — یک zip حاوی فایل APK است.
6. فایل APK را به گوشی اندروید منتقل کنید و نصب کنید (نیاز به فعال‌کردن «نصب از منابع ناشناس» دارید).

اگر بیلد قرمز شد (خطا داد)، روی همان run کلیک کنید و لاگ مرحله «Build APK with Buildozer» را ببینید — معمولاً پیام خطا مشخص می‌کند کدام بسته یا تنظیم مشکل دارد.

## اجرای محلی برای تست روی دسکتاپ (اختیاری)
```bash
pip install kivy arabic_reshaper python-bidi pillow
python main.py
```

## نکات مهم
- داده‌ها (شرکت‌ها و کالاها) به‌صورت JSON در فضای داخلی اپ روی گوشی ذخیره می‌شوند.
- دکمه ⚙ در بالای برنامه امکان گرفتن پشتیبان (Backup) و بازیابی (Restore) را می‌دهد.
- دکمه «خروجی عکس» از لیست کالاهای شرکت انتخاب‌شده یک فایل PNG در فضای داخلی اپ می‌سازد.
- رندر متن فارسی/راست‌به‌چپ در Kivy با کتابخانه‌های `arabic_reshaper` و `python-bidi` انجام می‌شود که در `buildozer.spec` و بالای این README به‌عنوان وابستگی اضافه شده‌اند.
- در صورت نیاز به آیکون اختصاصی اپ، یک فایل PNG مربعی (مثلاً 512x512) در `assets/icon.png` قرار دهید و خط زیر را در `buildozer.spec` (بخش `[app]`) اضافه کنید:
  ```
  icon.filename = %(source.dir)s/assets/icon.png
  ```

## نسخه وب (جایگزین سریع)
اگر فقط برای استفاده شخصی نیاز دارید و صبر برای بیلد APK ندارید، نسخه وب اپ (که قبلاً ساخته شد) را می‌توانید از مرورگر گوشی باز و به صفحه اصلی اضافه کنید؛ همان قابلیت‌ها را دارد ولی نیاز به نصب APK ندارد.
